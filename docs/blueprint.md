# **App Name**: Clichai

## Core Features:

- CSV Upload and Parsing: Allow users to upload a CSV file containing participant data, which is then parsed and stored.
- Data Storage in Firestore: Store participant data and meeting recommendations in a Firestore collection named 'parties'.
- AI-Powered Matching: Leverage Gemini 2.5 Pro to analyze participant data and recommend the best meeting matches for each individual, including a short explanation. The reasoning is done using the Gemini tool
- Recommendation Display: Display the meeting recommendations clearly, showing the matched participant and the reason for the match.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to convey innovation and connection.
- Background color: Light purple (#F3E5F5), a very desaturated version of the primary color.
- Accent color: Teal (#009688), an analogous color, but used for higher contrast.
- Font: 'Inter', a sans-serif font, for both headlines and body text.
- Use clear, professional icons for actions like 'upload,' 'match,' and 'save.'
- A clean, card-based layout to display participant data and meeting recommendations.
- Subtle transitions and animations when processing and displaying recommendations.
